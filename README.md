# موقع حجز تذاكر النقل البري

موقع حجز تذاكر النقل البري بين اليمن والسعودية.

## المميزات

- حجز تذاكر أونلاين
- دعم كامل للاتصال عبر الواتساب
- واجهة مستخدم عربية حديثة
- بيانات محلية قابلة للتخصيص

## التقنيات المستخدمة

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Radix UI

## التشغيل

```bash
npm install
npm run dev
```

## التخصيص

يمكنك تعديل البيانات في ملف `lib/queries.ts` لتغيير:
- المدن المتاحة
- الرحلات والأسعار
- المميزات
- آراء العملاء
- الأسئلة الشائعة
- إعدادات الموقع
